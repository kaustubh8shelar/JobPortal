# Job Portal

A full-stack Job Portal web application that connects job seekers with recruiters. It features AI-based job recommendations and applicant ranking for efficient hiring. Built with **Spring Boot** (Java) for the backend and **React** with **MUI** for the frontend.

## Features

- User registration and login
- Search and apply for jobs
- AI-powered job recommendations
- View and manage applications
- Recruiter job posting and applicant tracking
- Filters by location, experience, and skills

## Tech Stack

- **Frontend**: React, Material UI (MUI)
- **Backend**: Spring Boot (Java), RESTful APIs
- **Database**: MySQL (or your preferred RDBMS)
